# Sportz on Websockets

Real-time sports match data application built with React Router v7 and WebSockets.

## Setup

1. Install dependencies `bun install`
2. Copy `.env.example` to `.env` and ensure `PUBLIC_APP_URL` & `DB_FILE_NAME` are declared.
3. Run database migrations `bun db:setup`

## Development

```bash
bun dev
```
